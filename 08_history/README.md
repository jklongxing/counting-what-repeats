# Historical records

These files document earlier preparation steps, not current recommended analysis methods.

- `same_question_bootstrap.py` and `.json`: withdrawn same-question bootstrap. The manuscript reports the comparison descriptively. The previous weighting scheme could produce negative weights; do not use its interval or p value as a paper result.
- `AUDIT_REPORT_20261111.md`: historical preparation report, including superseded Countix values (57.8%). The final reported target-refit result is 56.5% after rounding, based on the five `countix_refit_seed*` runs.
- `MANIFEST_20261111.md`: historical file inventory and mapping, including counts and paths that no longer describe this release.

Current instructions and validation coverage are at the repository root. Earlier run artifacts retained in `02_predictions/` and `04_summaries/` are identified in the current manifest.
